# 合成大W

纯 **HTML + CSS + JavaScript** 的静态网页小游戏，零依赖、零构建、离线可玩。
物理引擎（PBD 位置约束求解）是自己写的，没有引入任何第三方库。

**在线玩**：<https://lacrimosa001-hub.github.io/dnw/>

手机上打开会提示「添加到主屏幕」，装完之后**全屏无地址栏，而且离线也能玩**。

## 玩法

- **鼠标**：移动瞄准，点击即投放
- **触屏**：按住拖动瞄准，**松手才投放**（手指不会挡住落点）
- 两个**同级**的 W 碰到一起就合成为高一级，并获得分数
- 顶上虚线是**警戒线**：有 W 卡在线上方并且基本停住、累计超过 1.5 秒即判负
- `←` `→` 微调位置，`Space` 投放，`R` 重开

合成链（8 级）：

```
哭泣 → 惊慌 → 无语 → 满足 → 得意 → 龇牙 → 大笑 → 暴怒
```
