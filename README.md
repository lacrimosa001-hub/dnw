# 合成大W

纯 **HTML + CSS + JavaScript** 的静态网页小游戏，零依赖、零构建、离线可玩。
物理引擎（PBD 位置约束求解）是自己写的，没有引入任何第三方库。

**玩法**：拖动瞄准、松手投放（鼠标是移动瞄准、按下即投）。
两个同级的 W 碰到一起就合成为高一级，并获得分数。
顶上虚线是警戒线：有 W 卡在线上方并且基本停住、累计超过 1.5 秒即判负。

合成链（8 级）：

    哭泣 → 惊慌 → 无语 → 满足 → 得意 → 龇牙 → 大笑 → 暴怒

手机上可以「添加到主屏幕」当 App 用，装完之后全屏无地址栏、**离线也能玩**。

## 运行

直接打开 `index.html` 即可（`file://` 协议下也能跑）。或起个静态服务：

    python -m http.server 8080
